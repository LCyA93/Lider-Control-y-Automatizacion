# v19.0.5.0.0 — Power BI Connector Fabric and REST Expansion
Status: [ACTIVE]
Date: 2026-06-23
Backlink: [[../00_overview]]

## Added
- Optional Microsoft Fabric integration inside `sh_power_bi_connector` without dependency on `sh_odoo_fabric_connector`.
- Fabric service-principal authorization, workspace/item discovery, supported item creation, Pipeline/Copy Job run tracking, and status polling.
- Power BI REST asset cache for workspaces, datasets, reports, and export jobs.
- Power BI dataset refresh, refresh history, PBIX import, report rebind, embed-token generation, and export-to-file tracking.
- Model Access target modes: `powerbi_push`, `fabric_kql`, and `fabric_pipeline`.
- Sync checkpoints, deleted-record tombstones, and Data Quality Validation wizard.
- Dashboard panels for Fabric configuration health and recent Fabric runs.

## Changed
- Manifest version bumped from `19.0.4.0.0` to `19.0.5.0.0`.
- Power BI REST helper now supports unscoped API calls and HTTP 202 responses.
- Menu declarations are centralized in `data/sh_powerbi_data.xml` so action/menu external IDs load in a predictable order.

## Compatibility Notes
- Existing Power BI push, queue, dashboard, embedded report, and `.mez` pull connector behavior remains available.
- Fabric menus are optional and can be ignored by Power BI-only installations.
- New persistent models include access rights and multi-company record rules.
